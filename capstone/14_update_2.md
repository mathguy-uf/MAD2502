# Update 2: Show Real Progress

[Capstone home](README.md) · [First Python Result](03_first_python_result.md)

**Update 2 is a 10-point evidence checkpoint. Submit one PDF per group.** Use Canvas for the deadline, exact grading breakdown, and submission location.

The goal is to show that your project is real and moving forward. A small reproducible result is useful evidence; a list of future plans alone is not.

Include:

1. **Your actual source and data.** Identify where the information came from and what a row or record represents. For tabular data, show the first five rows, last five rows, and dimensions using `head()`, `tail()`, and `shape`.
2. **Python code and actual output.** Show a meaningful piece of code your group has run and the result it produced.
3. **One first result.** Include a figure, table, count, summary, or other concrete result, with a sentence explaining what it shows.
4. **A problem or failed attempt.** Document an obstacle or branch of your research tree, the evidence you observed, what you learned, and what you changed or will try next.
5. **Individual contributions and next tasks.** State what each member has done and what each will do next.

You do not need to force a regression, classification model, simulation, or optimization method into this checkpoint. Use a method appropriate to the question and your current progress. A changed direction or unsuccessful attempt is acceptable when you show genuine work and explain the evidence.

Keep notes using **question → action → evidence → next step**. Those notes will help you write the [final report](08_final_report.md).
