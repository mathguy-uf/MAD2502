# Teaching data

- `campus_events.csv`: fictional campus events supplied with this course repository; one row is one event. Attendance is a count, cost is in dollars, and rating is a teaching score. Missing ratings are intentionally included. These are not actual UF student records.
- `statistics_villains_sample.html`: six-row, four-column excerpt from the instructor's [Statistics Villains page](https://people.clas.ufl.edu/mathguy/supervillain-statistics-playground/), checked October 24, 2026. Fictional characters and teaching costs; blanks preserved. The scraping notebook embeds the same excerpt so it works offline without a clone. This excerpt is not the complete page.
- The eBird notebook contains invented JSON records, explicitly labeled as sample data. It makes live requests only after `RUN_LIVE = True`.

Live sources can change. Record request parameters and access dates in your own project; share source data only when its license and privacy requirements permit it.
