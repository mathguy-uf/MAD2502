# Write the final report from evidence

[Capstone home](README.md)

The report documents the broader [research tree](06_research_tree.md). Start with journal entries, source notes, saved code, and figures. Organize them around the decisions that shaped the project.

## A useful structure

1. **Question and motivation:** what did you investigate, and why?
2. **Background and sources:** explain unfamiliar concepts and cite the sources you actually checked. A textbook can supply context that a specialized article assumes.
3. **Data:** source, access date, population/time period, row meaning, variables, units, and missingness.
4. **Process and methods:** how Python loaded and transformed the data; why you chose the analysis; meaningful detours and failed approaches.
5. **Results:** selected tables/figures, captions, and interpretation in plain language.
6. **Limitations:** what the evidence cannot establish and how decisions affect the result.
7. **Conclusion and next steps:** answer the question at the scale supported by the data.
8. **Reproducibility notes and references:** files, environment, exact run order, and source citations.

Follow Canvas for the required length, submission format, dates, and grading rules. Do not pad the report with unexplained code or repeat the same graph in several forms.

## Turn one journal entry into a paragraph

Journal: “API result had no attendance; found a CSV with attendance; kept the same question.”

Report: “The initial API source did not include attendance, which our question required. We switched to a documented CSV that included attendance and event location. This changed the data source while preserving the comparison we wanted to make.”

Then cite the real sources and explain any change in population or time period. Never invent an experiment or result to fill a gap in the journal.

## Accessibility and responsible assistance

Use actual heading styles, readable tables with header rows, meaningful link text, and figure captions that describe the main finding. Include text alternatives for essential visuals. Verify mathematical notation in the exported document. Check the current course policy before using AI assistance; verify citations and results and disclose use as required. Do not upload private student or restricted research data to an AI tool.
