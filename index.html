CAPSTONE · FINAL PROJECT

Document the research.
Demonstrate the results.

Your paper tells the full research story, including meaningful failures. Your presentation shows what works and the evidence supporting it.

Focus on a reproducible result, a defensible conclusion, and clear communication. Follow Canvas for official submission instructions.

Open final submission checklist

What your group submits

One ZIP
Python code, README, necessary ancillary files, and the paper as a PDF.
One coherent paper
Roughly 5 pages per student: sources, methods, decisions, successful and unsuccessful attempts, results, and limits.
10–12 minute presentation
For the whole group. Show a working result, an independent check or comparison, and a supported conclusion.

Presented in class? Post a note on the Canvas discussion board and attach your PowerPoint exported as a PDF.

Convince me that your research works

Claim → check → evidence → limit. Start with one small Python result, verify it independently, and explain what the data cannot prove. If the source or question changes, document why. Cite the main source and have a teammate reproduce the result using your README.

NEW TO GITHUB?

You only need a few things.

GitHub stores the course material. You can read a notebook there, run it in a hosted browser, or keep your own local copy with Git.

1
View on GitHubBest for reading code and saved output. Nothing runs.
2
Run in ColabUsually the easiest way to execute and change one notebook in a browser.
3
Launch BinderOpens the repository in a temporary browser-based JupyterLab environment.

Full Git & Jupyter guide

Terminal · first time only
$ cd Documents
$ git clone https://github.com/mathguy-uf/MAD2502.git
$ cd MAD2502
$ python -m pip install -r requirements.txt
$ jupyter lab
Terminal · later course sessions
$ cd Documents/MAD2502
$ git pull
$ jupyter lab
CommandWhat it does
pwdShow your current folder.
lsList files and folders.
cd folderMove into a folder.
cd ..Move up one folder.
git clone URLMake your first local copy.
git pullGet the newest course updates.
git statusSee files you changed locally.

Student rule of thumb: for this repository you normally need git pull, not git push. Make a personal copy before heavily editing an instructor notebook.

STUCK?

Start with the error, not with panic.

Read the message. Check the cell above it. Check variable names, types, file paths, and the selected Python kernel. Debugging is part of computational mathematics.
