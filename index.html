NEW TO GITHUB?

You only need a few things.

GitHub stores the course material. You can read a notebook there, run it in a hosted browser, or keep your own local copy with Git.

1
View on GitHubBest for reading code and saved output. Nothing runs.
2
Run in ColabUsually the easiest way to execute and change one notebook in a browser.
3
Launch BinderOpens the repository in a temporary browser-based JupyterLab environment.

Full Git & Jupyter guide

Terminal · first time only
$ cd Documents
$ git clone https://github.com/mathguy-uf/MAD2502.git
$ cd MAD2502
$ python -m pip install -r requirements.txt
$ jupyter lab
Terminal · later course sessions
$ cd Documents/MAD2502
$ git pull
$ jupyter lab
CommandWhat it does
pwdShow your current folder.
lsList files and folders.
cd folderMove into a folder.
cd ..Move up one folder.
git clone URLMake your first local copy.
git pullGet the newest course updates.
git statusSee files you changed locally.

Student rule of thumb: for this repository you normally need git pull, not git push. Make a personal copy before heavily editing an instructor notebook.

STUCK?

Start with the error, not with panic.

Read the message. Check the cell above it. Check variable names, types, file paths, and the selected Python kernel. Debugging is part of computational mathematics.
