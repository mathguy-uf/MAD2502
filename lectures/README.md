# MAD 2502 Lectures

[← Return to the course website](../)

These are the reviewed student-facing lecture notebooks for **MAD 2502: Computational Mathematics with Python**.

MAD 2502 is an introductory Python and data-science course. The notebooks assume that many students are programming for the first time.

## How the notebooks work

New and revised notebooks use the same learning rhythm:

**Understand → Predict → Run → Change → Use → Practice → Connect**

The guiding rule is:

> **Think first. Run second. Change something. Then use it.**

Chapter numbers follow *Python Programming and Numerical Methods*. Not every textbook chapter is a separate MAD 2502 notebook, and NumPy is listed as Chapter 2.7 because that is where it appears in the text.

## Which launch option should I use?

- **View on GitHub** — best for reading the notebook and its saved structure. Nothing executes.
- **Run in Colab** — easiest way to run and modify one notebook in a browser.
- **Launch Binder** — opens the repository in a temporary JupyterLab environment, which is useful when a notebook works with nearby repository files.

The course setup and Git tutorial are in [`START_HERE.md`](../START_HERE.md).

## Content standard

The canonical notebooks have been reviewed for current Python syntax, execution order, beginner pacing, and consistency with the relevant textbook topics. Intentional error demonstrations are labeled rather than left as unexplained broken cells. Advanced or environment-specific material is marked as optional where appropriate.

Optional examples such as OOP extensions and Turtle graphics live in [`examples/`](../examples/) rather than making the main lecture path more difficult.
